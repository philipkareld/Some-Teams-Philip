# Some Teams Philip

## Overview

A small PHP website that lists the teams in the UEFA Women's Europa Cup 2026/27 round of 16. Built as a school assignment at YRGO (WU26).

## How it's made

PHP for templating: require to share the header and data between pages, and foreach and endforeach to loop over the teams
No HTML inside PHP strings. PHP is only used to insert values (<?= ?>) and to loop
HTML and CSS for structure and layout (CSS Grid for the cards)

## Getting Started

- Clone the repository
- Install dependencies
- Run the project
- Or visit www.philipkareld.se
